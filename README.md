# 点訳エディタ（tenji-editor）

墨字（テキスト・Word）を点字データに、点字データを墨字（かな）に変換するエディタです。
左に読み込んだファイルをそのまま、右に1行ずつ「かな（分かち書き）」と「6点の点字」を並べて表示します。
変換したデータは、BSE・BRL・BRF・PEF などの形式で書き出して、ほかの点訳ソフトや点字ディスプレイで読めます。

- **ブラウザ版**：GitHub Pages で公開（インストール不要）
- **デスクトップ版**：Windows / Mac / Linux 用アプリ（Releases からダウンロード）

どちらもインターネットに接続せずに動きます。読み込んだファイルが外部に送られることはありません。

## できること

| | 読み込み | 書き出し | 備考 |
|---|---|---|---|
| テキスト（.txt） | ○ | ○ | UTF-8 / Shift_JIS を自動判別。Unicode 点字のテキストも読める |
| Word（.docx） | ○ | ○ | 見出し・表・枠・区切り線・画像を取り出す。画像は点図にする |
| Excel（.xlsx） | ○ | － | シートごとに中見出し＋枠で囲んだ表にする。日付・％、グラフ（データの表にする）、画像も読む |
| CSV（.csv・.tsv） | ○ | － | 枠で囲んだ表にする |
| PDF | ○ | － | 文字と画像を取り出し、原本のページ区切りを残す。段組み・表・カードの並びを読み分け、くり返すヘッダー・フッターは省く。スキャンしたページは全体を図にする |
| BSE（BASE形式） | ○ | ○ | NABCC コードのテキスト型。T・エディタ、ういんびー、点字ディスプレイなど。見本と同じ作り（512バイトのヘッダ「空白504＋ページ数4けた＋マス数2けた＋行数2けた」、各ページの1行目はページ行、FFなし、大文字） |
| BRL（NABCC） | ○ | ○ | 多くの点字ソフト・点字ディスプレイ・点字プリンタで読める |
| BRF（Braille Ready） | ○ | ○ | 英語圏の標準。Duxbury、BrailleBlaster など |
| PEF | ○ | ○ | XML の国際規格 |
| BES / BESX（点字編集システム） | ○ | ○ | 実物のBESを解析して、同じ作り（ヘッダ・ページごとの長さ・ページ行）で読み書きする。BESXは点字本文のみ |
| エーデル（.edl 点図） | ○ | ○ | 実物のエーデル図を解析。読み込んで書き戻すと元と同じファイルになる |
| BLS / BLE / BS（ブレイルスター）、BMT（ブレイルメモ）、NAB（コータクン）、BET | × | × | 仕様が公開されていないため未対応。元のソフトで BSE か BRL に書き出してから読み込んでください |

**点字編集システムで使いたいとき**：BES で書き出せます。うまく開けないときは、BSE か BRL で書き出して点字編集システムで読み込み、BES で保存し直してください。

### 変換の中身

墨字 → 点字

1. 漢字かな交じり文を形態素解析（kuromoji）して読みがなを付けます。
2. 点字の仮名遣いに直します（助詞「は」「へ」→「ワ」「エ」、ウ列・オ列の長音→長音符など）。
3. 文節で分かち書きをします（自立語の前で区切る、助詞・助動詞は続ける、複合語は3拍の目安で切れ続き、補助用言・形式名詞は区切るなど）。
4. 6点の点字にします（数符・つなぎ符・外字符・大文字符・拗音・特殊音・句読点と後ろのマスあけ）。
5. 書き出すときに、マス数・行数（既定は32マス×18行）に合わせて語の途中で切らずに折り返し、ページを分けます。

点字 → 墨字

- 点字を読み取って、分かち書きしたかなに起こします（数字・英字・記号も戻します）。漢字には戻せません。

### 点訳の書式と校正

- **行の種類**：右側の各行で「本文・大見出し・中見出し・小見出し・区切り線・枠の始まり・枠の終わり・表の行・図・空行」を選べます。見出しは7・5・3マス目から書き出し、前に1行あけ、ページの最後に見出しだけが残らないようにします。区切り線は棒線（⠒）、枠は第1種の枠線（⠖⠒⠲／⠓⠒⠚）で書きます。
- **ページ番号**：「ページ番号を付ける」で、各ページの1行目（ページ行）の28マス目から点字ページ番号を書きます。「原本ページも書く」で、ページ行の行頭に原本のページ番号を書きます（PDFのページ区切りや「［原本 12］」と書いた行から取ります）。
- **点訳者注**：かなを直す欄の「点訳者注 ⦅ ⦆」で、点訳者挿入符（⠠⠶ … ⠶⠄）を入れられます。
- **校正の支援**：「その後」「日本」のように読みが割れる語や、辞書にない語に印が付きます。候補の読みを押すと差し替わります。「前／次」ボタン（F8 / Shift+F8）で要確認の行へ移動できます。
- **6点入力**：点字→墨字の画面で「6点入力」をオンにすると、F・D・S・J・K・L（1〜6の点）の同時押しで点字を入力できます。スペースでマスあけです。

### 飾りと図

- **点字→墨字**：区切り線・枠線・点図・ページ行は、かなとして読まずに、墨字では「────」「┌──┐」や点の形のままの図として起こします。
- **墨字→点字**：Wordの段落罫線（四方なら枠、上下だけなら区切り線）、表、Excelの表は、点字の枠線とセル間の2マスあけで書きます。画像は白黒にして点図（1マス＝横2点×縦3点）にします。点図にしたくないときは、図の行のチェックを外すと「⦅図⦆」とだけ書きます。

### 書式（BSEの見本に合わせる）

見出しは7・5・3マス目から、2行目以降はさらに2マス下げる。行頭の記号の印は「⠔⠔」＋マスあけ。語の間の全角スペースは2マスあけ。ページ番号はページ行の28マス目から（既定で付ける）。

### 枠と表

枠線は1マス目から行いっぱいに引き、枠の中はふつうの書き方。表は列の頭を縦にそろえる。1行に入らない表は、最後の列の中で折り返す → 1列目をくり返して分割する → 「列の名前：値」で項目ごとに書く、の順で形を選ぶ。ページをまたぐ表は見出しの行をくり返す。画面では表と枠を1枚のカードにまとめ、列ごとに色分けして表示する。1ページに入る枠はページの途中で切らない。

### 記号

点字の記号があるもの（句読点・カッコ・矢印・斜線・数式の＋×÷＝など）は記号で、ないもの（％・℃・¥・＆・＠・○・ギリシャ文字など）は読みに置き換える。丸数字や㈱・㎝などの互換文字は普通の文字にしてから点訳し、箇条書きの印・絵文字は省く。辞書にない漢字の語は1字ずつ読んで「要確認」に残す。

### 点訳の正確さ

厚生労働省「点字ダウンロード」の公式の点字データ（65段落・1,093語）と、読み・分かち書きを比べるテストがある（`test/official.test.js`）。いまは公式と違う語が13語（辞書の読み・見出しの折り返しによるもの）。

だれでもダウンロードできる公式の点字データ（厚生労働省の約520ファイル、日本語能力試験、名古屋市・つくば市・文京区などの広報の点字版、あわせて約1,400ファイル・約150万行）で書き方を確かめた。

- 読み込み：公式の点字を読んで書き戻すと、99.5％の行がもとと同じ点字になる。
- 点訳：厚生労働省の墨字のPDFを点訳して公式の点字と語ごとに比べ、違う語の割合を 14.1％ から 8.9％ に減らした（残りの多くはPDFから文を取り出すときのずれ）。
- 分かった規則（小見出し符 ⠠⠤、％ ⠰⠏、注記符 ⠰⠼⠁⠆、空欄符号 ⠸⠭⠭⠇、伏せ字、点訳者挿入符 ⠶⠶、アドレス囲み符号 ⠠⠦…⠠⠴ と情報処理用点字、日付の読み、法令の読み・分かち書きなど）は `test/corpus.test.js` で確かめる。点字データそのものはリポジトリに入れていない。

### 数式（数学点字）

文部科学省「点字学習指導の手引」（令和5年）第8章の書き方で、文の中の数式を数学点字にする（`test/math.test.js`）。式の中はマスをあけず、数字で始まらない式には数式指示符 ⠰。＋ ⠢、－ ⠔、× ⠡、÷ ⠌⠌、＝ ⠒⠒、＜ ⠔⠔、＞ ⠢⠢、（ ） ⠦ ⠴、分数 ⠷…⠌…⠾、根号 ⠜、2乗 ⠣・3乗 ⠩・累乗 ⠘、1桁の添え字 ⠠＋下がり数字、単位の2乗・3乗（⠰⠍⠣）。± は ⠢⠔（＋の下に－）、≦ ≧ は ⠔⠔⠒⠒・⠢⠢⠒⠒（資料で確かめられないので校正の一覧に出す）。化学式は指示符 ⠰⠠・下がり数字・カッコ ⠣ ⠜、反応式の ＋ → は前後をあける（手引 第8章第4節の例と同じ点字になる）。点字の式・化学式も読み戻す。≠ ≒ ∞ π などは資料で形を確かめられないため、いまは読みで書く。

### 英語の発音記号

[ ] や / / で囲んだ発音記号を、日本点字表記法（文部科学省「点字学習指導の手引」の表）の発音記号の点字にする。発音記号符 ⠰…⠆、第1ストレス符 ⠸・第2ストレス符 ⠘ は母音の前（ˈ ˌ は次の母音の前へ移す）、長音符 ⠒。

### 図・写真・グラフの読み込みと書き出し

- グラフ（Word・Excel）は項目と数値の表にして点字にする（円グラフは割合も）。
- 線画は点字のマスで描いた点図にして本文に入れる。写真は本文に「⦅図N 写真 点図は別紙⦆」と注記だけ書き、点図を右側に表示する。
- 点字形式で書き出すとき、点図があれば「点図が含まれています」の確認を出す。Enter＝本文と点図をZIPにまとめて保存、スペース＝本文だけ、Esc＝戻る。点図の形式（点図プリンタ用PDF・立体コピー用PDF・エーデル・SVG）を選べる。

### 点図ファイル（マス目に縛られない点図）

図の行の「点図の調整・手直し・書き出し…」で、本文とは別の点図ファイルを作れます。点は用紙全体に等間隔（既定2.5mm）で打つので、本文の32マス×18行やマス目の制限を受けません。

- **点図プリンタ用（PDF / SVG）**：黒い部分に点を打ちます。点の間隔と大きさ（大1.6mm・中1.2mm・小0.8mm）を選べます。ViewPlus Tiger などの、画像やPDFを点図として打ち出せるプリンタ向けです。
- **立体コピー用（PDF / SVG）**：黒い部分を塗りつぶして描きます。カプセルペーパーに印刷して立体コピー機に通す使い方です。
- 図の見出しをかなで入れると、点字（点の並び）にして図の上に入れます。
- 用紙は A4・B5・点字用紙（8×10インチ）・B4・A3、縦横を選べます。画像ファイル（PNG・JPEG・GIF・WebP・HEIC など）を直接開いても点図にできます。
- 色の判定：画像の色を Lab 色空間の k-means で数色にまとめ、色の境目を線にする。色の境目・透明な背景の外形・線画（局所的に暗い細線）・明るさの変化（キャニー法）を組み合わせ、二重線は足さない。見つけた色を日本語の色名と割合で一覧にし、色ごとに線だけ／塗る（3段階）／省くを選べる。画像のふちに多い色は背景。
- 画像処理（AIなし）で、描き方（色の境目・外形・輪郭線・塗り）、ノイズ除去、コントラスト、点にする濃さ、輪郭の感度、線の太さ、塗りの密度、点の間隔を調整できる。輪郭線はソーベル＋細線化＋ヒステリシス（キャニー法の考え方）。
- 点を1点ずつクリックで打つ・消す、ペン・消しゴムでなぞって描く・消す、キーボード（矢印＋スペース）でも直せる。手直しは図の枠に対する位置で覚えるので、調整を変えても残る。
- **エーデル（.edl）**：8×10インチの点字用紙に、点で打つ形で書き出します。エーデルの図を開いて、PDF・SVGや別の大きさの点図にすることもできます。点の種類の数字（1〜4）と点の大きさの対応、1目盛りの長さ（横約0.4mm・縦約0.34mm）は、点字の点の間隔から推定したものです。

### 自動変換の限界

自動の点訳には限界があります。書き出す前に、右側の「かな」を必ず確認してください。かなは直接書き直せて、直すと点字も変わります。

- 同じ漢字で読みが変わる語（「その後」をソノゴ／ソノ アトなど）や、固有名詞の読みは間違えることがあります。
- 「4日（ヨッカ）」のような数字の読み分けや、「関東一円」のような数字を仮名で書く慣用句は判断しません。
- 点図は画像を単純に白黒にしたものです。写真や細かい図は、点訳者が手で整えるか、説明文に置き換えてください。
- 縦書きのPDFや、文字の順番が崩れているPDFは、正しく取り出せないことがあります。PDFの中で線で描かれた図（画像でないもの）は取り込めません。
- 写真か図かの判定は自動で、間違えることがあります。
- 辞書にない漢字は「未変換」と表示し、点字ではめの字（⠿）で仮置きします。

## 使い方

1. 「ファイルを開く」でファイルを選ぶか、画面にドラッグ＆ドロップします。左の欄に直接入力・貼り付けもできます。
2. 右側で、かなと点字を1行ずつ確認します。かなをクリックすると書き直せます。
3. 「書き出す」から形式を選んで保存します。

まとめて変換：ZIP（または複数のファイル）を開くと、中のファイルを全部変換し、「前のファイル／次のファイル」（Alt+PageUp／Alt+PageDown）でめくれる。手直しはファイルごとに残り、「まとめて書き出す」で全部を同じ形式で1つのZIPに書き出す。Shift_JISのZIPのファイル名にも対応。

ショートカット：Ctrl+O（開く）、Ctrl+S（BSE で書き出す）、F8 / Shift+F8（次／前の要確認）

## スクリーンリーダーでの使い方

VoiceOver（Mac・iPhone）、PC-Talker、NVDA、JAWS、ナレーターなど、OSのアクセシビリティの仕組みを使うスクリーンリーダーで操作できるように作っています。

- **画面の構成**：ページの先頭に「変換データへ移動」「読み込んだファイルへ移動」のリンクがあります。見出し（h1・h2）でも移動できます。
- **行の読み上げ**：右側の変換データは1行ずつ「3行目、ブライユガ ウマレタノワ…、点字 38マス、要確認」のようにまとめて読みます。点字のマスを1つずつ読ませることはしません。
- **点の番号で読む**：上の「点字の読み上げ」を「点の番号も読む」にすると、「1 2 4の点、マスあけ…」のように点字の中身も読みます。
- **キー操作**：変換データの中では、上下の矢印キーで行を移動し、Enterでかなを直します（Enter か Esc で確定して行に戻ります）。Home／Endで最初／最後の行、PageUp／PageDownで10行ずつ移動、F8／Shift+F8で次／前の要確認の行へ移動します。
- **お知らせ**：ファイルの読み込み、保存、かなを直したあとの点字のマス数、6点入力で入れた文字（「ア、1の点」など）、読みの候補を選んだ結果を、読み上げでお知らせします。
- **校正箇所の一覧**：上の「校正箇所の一覧」ボタン（F7）で、読み方を判定できなかった箇所・辞書にない語・読めない点字の一覧を開きます。項目を選ぶとその行へ移動します。
- **書き出す前の確認**：校正されていない箇所が残ったまま書き出そうとすると、確認の画面が出て読み上げられます。Enterで続ける、Escで戻る、スペースで校正箇所の一覧へ移動します（同じ名前のボタンもあります）。
- **書き出しメニュー**：「書き出す」を押すと形式の一覧が開き、上下の矢印キーで選んでEnterで保存します。Escで閉じます。
- Windows のハイコントラスト表示にも対応しています。

NVDA は、文字入力欄（左の原文や6点入力の欄）に入ると自動でフォーカスモードになるので、そのまま入力できます。

## 開発

ビルド不要の静的サイトです。

```bash
# ブラウザ版をローカルで動かす（辞書を読み込むため、ファイルを直接開かずにサーバー経由で）
python3 -m http.server 8000   # → http://localhost:8000

# テスト
npm test

# デスクトップ版
npm install
npm start          # 起動
npm run dist       # インストーラを作る（release/ に出力）
```

- `js/engine.js`：点訳エンジン（かな化・分かち書き・点字化・逆変換・レイアウト）
- `js/formats.js`：ファイル形式の読み書き
- `js/app.js`：画面
- `electron/main.js`：デスクトップ版

### 公開のしかた

- **ブラウザ版**：リポジトリの Settings → Pages で Source を「GitHub Actions」にすると、main に push するたびに自動で公開されます。
- **デスクトップ版**：`v1.0.0` のようなタグを push すると、Windows（.exe）・Mac（.dmg）・Linux（.AppImage）のアプリが作られて Releases に添付されます。コード署名をしていないため、初回起動時に OS の警告が出ることがあります。
